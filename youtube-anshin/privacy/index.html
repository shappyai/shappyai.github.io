PRIVACY POLICY

プライバシーポリシー

「大人のデジタル安心室 YouTube Upload Tool」（以下「本ツール」）が、Google OAuth 2.0およびYouTube Data APIを利用する際の情報の取り扱いを説明します。本ツールは個人利用のために運用しており、一般利用者向けの公開サービスではありません。

このページの内容 利用目的 Google OAuth / YouTube API 取り扱う情報と保存 第三者提供とLimited Use 権限取消と削除 セキュリティ

1. 利用目的

本ツールは、利用者本人が管理する「大人のデジタル安心室」のYouTubeチャンネルへ動画をアップロードし、アップロード結果や必要な動画情報を確認・管理する目的に限って、GoogleおよびYouTubeの権限を利用します。

本ツールは、一般利用者のアカウントを登録してサービスを提供するものではありません。

2. Google OAuth / YouTube API

本ツールは、Google OAuth 2.0で利用者の同意を得たうえで、YouTube Data APIと通信します。実装上設定している権限は次の2つです。

  • YouTubeへの動画アップロード：youtube.uploadを使い、動画をYouTubeへ送信します。
  • YouTube動画・チャンネル情報の確認と必要な更新：youtube.force-sslを使い、アップロード処理に必要な情報を確認・更新します。

本ツールの実装では、対象チャンネルの確認、動画のアップロード、サムネイルの設定、アップロード後の動画情報の確認、必要な動画管理情報の更新を行います。権限名が示す範囲に含まれ得る機能を、目的外に利用するものではありません。

Google OAuthの同意画面に表示される権限と、本ツールの利用目的を確認してから許可してください。

3. 取り扱う情報と保存

本ツールの実行時には、次の情報を、YouTubeへのアップロードと結果確認に必要な範囲で取り扱います。

  • Google OAuthの認証情報（アクセストークン、更新用トークンなど）
  • 対象チャンネルの確認に使うチャンネルIDやチャンネル名
  • アップロードした動画の動画ID、処理結果、公開状態など
  • 利用者がアップロード対象として指定した動画ファイルとメタデータ
  • 処理確認のための実行ログ・診断情報（認証状態、チャンネルID、動画ID、メタデータの一部など）

OAuthの認証情報は、利用者が実行するローカル環境に保存されます。本ツールのために、これらの認証情報を独自の外部サーバーへ保存する仕組みはありません。ログや診断情報も、ツールの実行環境に保存されます。

この公開ページ自体は静的HTMLで構成され、外部JavaScript、Cookie、アクセス解析、広告用トラッキングを使用しません。

4. 第三者提供とGoogleのLimited Use

取得したGoogleユーザーデータを販売しません。広告目的や広告の最適化に使用しません。Google OAuthおよびYouTube APIの機能提供に必要なGoogle / YouTubeとの通信を除き、目的外で他の第三者へ意図的に提供しません。

本ツールによるGoogle APIから取得した情報の使用および他アプリへの転送は、Google API Services User Data Policy（Google公式）および同ポリシーのLimited Use requirementsに従います。

Google API Services User Data Policyを確認する

5. 権限の取消しとローカルデータの削除

Googleアカウントからアクセス権を取り消す

Googleアカウントのリンク済みアプリの管理ページを開き、対象アプリを選択してください。画面内の「Googleアカウントへのアクセス」または同等の項目から詳細を確認し、「アクセス権を削除」または「Remove access」を選択して確定します。表示される項目名は、Googleアカウントの言語や画面によって異なる場合があります。

Google公式ヘルプ：Googleアカウントと第三者アプリの接続を管理する

ローカルに保存された認証トークンを削除する

本ツールを使わなくなったときは、利用者のローカル環境に保存された認証トークンファイル（token.json）を削除してください。削除後に本ツールを使う場合は、再認証が必要になります。

保存期間とYouTube上のデータ

認証情報は、本ツールの利用に必要な期間、利用者自身のローカル環境に保持されます。Googleアカウント側でアクセス権を取り消すか、ローカルトークンを削除すると、その認証情報による利用はできなくなります。YouTubeへアップロード済みの動画やその情報は、YouTube側のアカウントに残るため、必要に応じて利用者がYouTubeの機能から管理してください。

6. セキュリティ

OAuthトークンやOAuthクライアントの秘密情報は、公開リポジトリやこの公開ページへ掲載しません。認証に使う秘密情報やトークンの実値をHTMLに含めない運用としています。

ローカル環境に保存される認証情報とログは、利用者自身の端末の安全管理のもとで取り扱ってください。
